EASIEST FREE HOSTING OPTIONS

GitHub Pages:
1. Create a new GitHub repository.
2. Upload ALL files from this folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and / (root), then Save.
6. GitHub will give you an HTTPS site address.
7. Open that address on your iPhone.

Install on iPhone:
- Safari: Share > Add to Home Screen > Add.
- Chrome on iPhone: open the hosted site, tap Share, then Add to Home Screen if shown.
  Safari is the most reliable method for installing iPhone web apps.

IMPORTANT
Your workout data is stored locally in the browser/app on that device.
Deleting site data, clearing browser storage, or removing the web app may erase saved entries.
